# 图文验收材料

用固定阅读器呈现用户需要判断的问题。任务提供事实、图片与来源，生成器负责排版和文件复制。优先复用当前任务已有证据；不为凑页数重新采集，不默认读取其他任务历史。

## 准备材料

先读 [取景与配文](references/capture-and-copy.md)，为每个问题选择单图、对照、离散状态序列或文字证据页。一页回答一个问题，不强制一页一张图。

读取 [数据合同](references/content-contract.md) 后，在任务独立目录准备 `task.json` 与所引用素材。历史资料只能在用户要求或明确引用时使用，并标为历史；模拟器、真机、Web 和 Electron 来源分开记录。记录缺失值，不根据图片或文件修改时间推测动作、时间、对象身份。

需补截图时使用任务所在环境的取证工具；Runweave 中 Web/Electron 路由到 `toolkit:playwright-cli`、iOS 路由到 `toolkit:agent-device`。本技能不创建新的采集服务，不因整理材料启动产品修复。需要连续过程或真实耗时的结论不能仅由离散图支持。

## 生成和本地打开

脚本相对本 `SKILL.md` 定位，不假定调用工作目录。只需 Python 3.9+ 标准库。

```bash
python3 <本技能目录>/scripts/gallery.py validate --input-root <输入目录> --input task.json
python3 <本技能目录>/scripts/gallery.py build --input-root <输入目录> --input task.json --output <新的成果目录>
python3 <本技能目录>/scripts/gallery.py serve --directory <成果目录> --port 0
```

`validate` 只校验输入；`build` 拒绝覆盖旧目录，完整输出 `index.html`、模板、素材和哈希。整个成果目录可复制，直接打开 `index.html` 不需要服务或外网。

`serve` 前台绑定 `127.0.0.1` 动态端口，打印 URL、PID 与停止说明。只服务成果清单中的文件；不是任意目录文件服务器。前台用 Ctrl-C 停止。用户需要保留链接时可将该命令作为独立进程启动，将 PID、完整命令、启动时间和输出目录记在成果目录之外；停止前核对身份，不使用宽泛进程匹配。服务结束后原链接失效，重启读取实际端口。

## 交付前检查

- 先运行校验与生成，再实际打开页面逐页核对图片、文案、来源和取景。原图需能打开；无 UI 的任务不硬配图片。
- Runweave 中按 `toolkit:playwright-cli` 检查翻页、目录、刷新定位、展开返回，以及桌面和窄屏；独立成果页使用隔离浏览器，不覆盖用户的产品页。若工具不可用，报告尚未执行的浏览检查，不把结构校验写成 UI 验收。
- 结构校验不等于图像可解码；浏览检查不等于业务通过。只对实际完成的检查作出结论。
- 给实际可用的本机 HTTP 链接及绝对文件路径。没有服务时只给文件路径。另一台设备不能访问本机 `127.0.0.1`，不描述为远程链接。
- 素材与报告默认本地保存；不上传、不自动写入业务状态。任务另有随记要求时遵循随记 Skill，仅追加成功最终成果，完成状态需用户明确确认。

不运行插件同步或全局安装来交付一次报告。源码落盘与新会话已加载技能是两件事。
