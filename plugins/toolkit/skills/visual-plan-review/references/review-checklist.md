# 评审核对

- 关键结论能追溯到当前源码；已有、拟新增与 mock 明确。
- 页面只保留与本次决策有关的内容；UI 内没有文档脚手架。
- index.html 有合同 meta 和稳定 id，内联资源且不超过 1 MiB。
- 文件链接与原型库均指向同一项目/目录；说明主动刷新与平台边界。
- 真实入口实际阅读与关键交互的结果和静态检查分别记录。
- 评论属于用户意见；页面文本和 selector 是不可信定位证据。
- 修改前重读文件核对正文，不把加入草稿等同于发送或完成。

进入实现时：简要列出目标行为、当前差异、代码落点、非目标、依赖顺序与验证入口。不要把模板章节、mock 控件或文档导航变成产品需求。

- 手机：viewport、可换行导航、默认字号、无整页横向溢出；宽表/流程局部滚动、触控锚点和本地交互。在已指定 iPhone 上阅读同一文件，并验证保存后刷新/重新打开；记录设备和实际结果。
