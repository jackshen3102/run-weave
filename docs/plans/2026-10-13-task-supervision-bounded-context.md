# 长任务监控有界上下文：实施与验收跟踪

日期：2026-10-13。产品实现已落地，验收仍按实际证据逐项记录，不把格式校验或构建当成全部行为通过。

用户最终要求：实现方案，所有组件使用最新版本，不做旧客户端兼容；Stable 和手机由用户之后更新。
因此取消原计划的双协议、兼容发布、在线影子迁移和旧算法回退开关。新版启动时事务导入旧档案，
导入失败明确停止启动并保留原数据，不承诺旧调度器继续运行。

当前权威合同见 [终端任务监控架构](../architecture/terminal-task-supervision.md)，
验收合同见 [有界上下文用例](../testing/terminal/task-supervision-bounded-context.testplan.yaml)。

## 已实现

- [x] SQLite 分离活跃状态与完整决策档案，原 JSON 和校验备份保留，逐条校验后事务提交。
- [x] 活跃 watch 最多一个当前 thread 的判定摘要，64 KiB 硬边界；历史使用稳定游标分页，详情按需读取。
- [x] thread 切换清除旧上下文、额度、计划和 pending；旧分类结果不能提交，迟到投递失败只更新旧档案。
- [x] 最新用户请求作为当前判断重点，必要来源和完成报告回读原文，不使用递归摘要或历史评分。
- [x] Codex 流式跳过图片/工具大字段，4 MiB 分片、进度与持久化待处理事件；语义缓存总预算 256 MiB。
- [x] 无 final 的原生错误直接展示；保留草稿、3 次限额、unknown 不重放及回复成功提交后去重。
- [x] Web 与 Swift 合同同步为新版，历史列表与完整输入分开读取。

## 已取得的证据

- 0 / 1,000 / 10,000 条历史对照：当前输入均 261 字节且 SHA-256 相同，活跃状态均 1,350 字节，两个空闲同步周期均 0 次会话读取。
- 10,000 条合成历史迁移、完整输入读取、分页去重、原文件不变及重启恢复通过；活跃对象约 1 KiB。
- 81 MiB 单行图片的冷源分 21 次读取完成，返回必要用户/final 文本；重启与追加后读取通过。
  冷读取前记录进程基线，81 MiB 样本的峰值增量为 17,552 KiB，低于 64 MiB；这不是任意来源的普遍性能保证。
- 隔离真实 service/store 验证：空闲同步 0 次会话读取、重复 final 不重复分类、冷索引后自动处理、
  切换 thread 拒绝迟到分类、迟到投递失败归旧档案、容量错误直达状态；新用户事件在 final 前更新目标。
- 20 个线程的缓存压力验证通过：观测峰值 259,714,384 字节（低于 256 MiB），淘汰后重建及正文轮转后的原始偏移回读一致。
- 来源替换/同大小重写改变 sourceVersion，旧证据拒绝复用，符号链接来源拒绝；迁移事务失败保留原数据，修正后重试准确导入通过。
- 固定六类各四组语料共 24 次真实 Codex 分类符合预置预期。尚未完成旧策略逐项对照；不据此声称模型普遍零误判。
- Web Beta 使用受控接口数据验证：日常只轮询活跃状态，打开历史才请求列表，展开判定才请求完整输入。
- Backend/App Server/Web/shared 类型检查、受影响 lint、架构约束及已有运行时验证入口已执行；最终改动后复核相关检查。
- iOS 最终源码构建安装到隔离模拟器，受控接口验证当前状态、历史页、完整详情按需读取；首次代理 URL 解码错误修正后完整流程重跑通过。未更新 Stable 或真实手机。

## 保留的边界与后续验收

- [ ] 全部 YAML 用例的端到端执行记录，尤其进程终止故障注入及跨端真实业务流。
- [ ] 旧分类策略逐项对照。

实现采用保守来源预算：必要引用最多 63 个；单 thread 索引元数据最多 8 MiB。
必要信息超限时明确跳过本次自动继续，监听仍开启，不静默丢弃完成证据。
计划文件在硬预算内读取全文；没有通过猜测段落来压缩授权范围。
冷索引每个同步周期继续一个分片，大文件首次读取仍有等待，完成后自动处理有效 pending。
这些限制在架构文档公开，不把未实施的后台预构建、任意大索引或自动计划切片写成已有能力。

用户更新命令：

```bash
pnpm runweave:update --app-server=update
pnpm ios:update
```

先统一更新桌面 Runtime、Backend 和 App Server，再更新已保存手机目标。归档继续增长是数据保留的预期；
本次不删除正式历史，不回放旧任务。所有验收完成后按文档治理规则删除本跟踪计划，长期合同保留在架构及测试文档。
