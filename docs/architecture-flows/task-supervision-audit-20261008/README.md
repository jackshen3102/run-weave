## 本次收敛实现

在 `16f2c232` 基线与已有改动上，根据用户“不必十项全做，必须解决实际问题”的要求，收敛为四项：

1. 具体下一步与已有授权一起交给原会话，精简重复原则，保留必要验证。
2. 按实际用户范围区分局部等待、真正外部阻塞和自拟额外任务；已有授权不重复确认。
3. 最近对话先过滤监督模板和 Hook，保持原有 4 条窗口，撤回无单独效果证据的扩容。
4. 未开始投递的取消不记未知并退还同轮额度；分类成功才提交去重游标。
