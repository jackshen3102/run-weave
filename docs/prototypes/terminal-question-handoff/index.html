核心流程

确认原请求后发提醒，打开时再核对一次。

  1. Codex提出问题原任务等待回答
  2. Backend确认原请求匹配线程、轮次和问题
  3. iPhone收到提醒点开进入原问题
  4. Runweave核对当前状态仍待答时展示选项
  5. 原终端收到答案，继续答案写回同一条请求
