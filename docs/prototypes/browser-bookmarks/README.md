# 浏览器收藏夹交互原型

2026-10-17 的设计讨论产物，曾作为收藏夹 v1 的交互基线；属于历史原型，不代表当前 Runweave 已实现这些能力。

## 打开

在仓库根目录运行，无需构建：

```bash
python3 -m http.server 6188 --bind 127.0.0.1 --directory docs/prototypes/browser-bookmarks
```

访问 <http://127.0.0.1:6188/>。通过 `?reset=1` 恢复样例收藏，随后打开不带参数的地址；重置参数仅用于原型演示。

## 原型简报

目标：沿用 Chrome 的收藏习惯，让用户保存当前网页、快速打开常用网站，并做简单整理。

挂载位置：现有桌面项目、终端、右侧浏览器布局中的浏览器地址栏与下方收藏栏。对应真实模块为 `frontend/src/components/terminal/browser/header/navigation.tsx`；原型没有导入或修改产品源码。

主要流程：地址栏星标 → 自动收藏当前页 → 编辑名称和网址、选择文件夹 → 完成。已收藏页面再次点击星标进入编辑，可移除收藏。收藏栏点击打开，右键可在新标签页打开、编辑或删除。

关键状态：未收藏、已收藏、编辑弹窗、文件夹菜单、收藏栏溢出、搜索结果或空结果、收藏栏隐藏、删除非空文件夹确认。

## 当前采用的交互

- 一行可隐藏的收藏栏，放不下的条目进入 `»` 菜单。
- 一级文件夹；收藏时可创建文件夹并自动选中。
- 拖动链接调整顺序、移入文件夹；拖动文件夹调整根级顺序。通过编辑收藏选择“收藏栏”可移出文件夹。
- 顺序由用户控制，不按访问频率变化。
- “收藏夹”打开轻量侧栏，支持名称和网址搜索、逐项编辑。
- 收藏栏隐藏后仍可从浏览器菜单打开收藏夹。
- 共享一份收藏是本次原型假设；Profile 隔离、跨设备同步、移动端归属尚未确定。

本轮收敛为普通浏览器收藏，不展开项目专属收藏、稍后阅读、随记联动。未纳入第一版的方向包括多层文件夹、导入导出、独立管理页面和云端同步。

## 功能分类与模拟边界

| 分类         | 内容                                                                                         |
| ------------ | -------------------------------------------------------------------------------------------- |
| 产品核心意图 | 星标、收藏栏、一级文件夹、右键菜单、编辑删除、拖动排序、搜索、溢出菜单、显示偏好             |
| 原型辅助     | `?reset=1` 恢复数据，不提供画面中的辅助按钮                                                  |
| 模拟环境     | 项目列表、终端内容、Profile 指示与网页正文；网址跳转和新标签页只在原型中模拟，不加载外部网站 |
| 模拟存储     | 当前浏览器 localStorage；并非产品数据库、Profile 存储或同步协议                              |

小于 800px 时仅显示浏览器区域，便于在 Runweave 右侧 Browser 内查看；这不是移动端产品设计。

产品代码已实现，当前合同和验证入口见[收藏夹文档](../../../frontend/docs/browser-bookmarks.md)。产品采用同一 Desktop 实例共享收藏、Mac 桌面优先，以及主进程独立存储、IPC 权限和原生浮层协调。原型作为历史交互参考保留，不能代替产品验收。

## 已执行的交互检查

通过仓库固定版本 Playwright CLI 附着 Runweave Terminal Browser 的解析后 Profile 1，在新建的原型标签页执行；保留原有标签页。

- 添加收藏、改名、移入工作文件夹；刷新后名称和文件夹保留。
- 拖动调整顺序、刷新保留；拖动链接进入文件夹。
- 收藏过程中创建文件夹并自动选中。
- 按名称和网址搜索，以及无匹配结果。
- 隐藏收藏栏、刷新保留、通过菜单继续访问收藏夹。
- 右键在原型新标签页打开、确认目标地址、移除收藏后星标更新。
- 1000 × 760 窄窗口下通过溢出菜单访问隐藏收藏；1440 × 900 整体布局截图。

上述检查验证原型交互，不代表产品端到端验收。
