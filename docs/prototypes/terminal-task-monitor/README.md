# 长任务监控交互原型

2026-10-06 的历史交互原型。产品现已实现；本目录仍只包含当时的样例数据和模拟交互，不能作为当前产品实现或验收证据。当前行为和版本边界见 [长任务监控架构](../../architecture/terminal-task-supervision.md)。

## 打开

仓库根运行（不需要构建，也不需要 Jev 或 Codex 凭据）：

```bash
python3 -m http.server 6197 --bind 127.0.0.1 --directory docs/prototypes/terminal-task-monitor
```

打开 [正在监听](http://127.0.0.1:6197/)。同机浏览器可访问，其他设备不能通过此回环地址访问。

- [从开启入口开始](http://127.0.0.1:6197/?scenario=off)
- [达到三次上限](http://127.0.0.1:6197/?scenario=limit)
- [已完成](http://127.0.0.1:6197/?scenario=completed)
- [受阻](http://127.0.0.1:6197/?scenario=blocked)
- [正在判断](http://127.0.0.1:6197/?scenario=reviewing)
- [暂停](http://127.0.0.1:6197/?scenario=paused)

从未开启状态点击开启，确认目标后显示 0/3；每轮最终回复由独立监听 Agent 三分类。原 Agent 工作时只显示等待，不介入。可继续时在原终端显示续接消息并累计次数。达到 3/3 后若仍未完成，显示“已达续接上限”，用户可明确重新开启一轮。

暂停/恢复不重置次数，也不清空未提交草稿。判定详情展开本次评分来源与目标。只有“重新开启一轮监控”确认后归零；取消保持原状态。

## 画面与功能边界

| 分类             | 内容                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| 产品核心交互     | 开启目标确认、仅最终回复、独立监听 Agent、三分类卡片、续接计数、暂停/恢复、次数耗尽与重新开启        |
| 页面背景         | 工作区导航、终端 tab 和代码检查样例，仅用于呈现上下文；导航不是本次实现范围                          |
| 原型辅助         | scenario 参数、autoplay 参数、window.prototypeMonitor 事件入口；不在产品画面中显示，也不进入正式产品 |
| 原型不具备的能力 | 原任务事件监听、Codex 推理、真实输入投递、身份隔离、持久化和重启恢复；真实产品以当前架构和源码为准   |

`index.html` 放挂载点，`style.css` 放布局样式，`app.js` 放交互，`mock-state.json` 放样例目标、评分与事件。不导入生产源码，不发送真实消息，不启动 Agent。

此历史原型采用终端主体加右侧监控面板。展示三项评分但不将它们叫作统计正确率。上限状态与业务“完成/阻塞”分开；原型没有自动识别任务、第二套验收 Agent、Jev 凭据配置或产品内模拟按钮。

## 演示辅助（不进入产品）

追加 `autoplay=1` 后，每 5 秒产生一组样例中间回复和最终回复，演示最终回复驱动的有限循环。默认关闭，确保截图状态稳定。

例如 [从开启到上限的自动演示](http://127.0.0.1:6197/?scenario=off&autoplay=1)：点击开启后，前三轮 final 各增加一次续接，第四轮仍为可继续时停在 3/3。中间回复不改变计数。

浏览器验证可以调用 `window.prototypeMonitor.receive({phase: 'commentary'})` 或 `receive({phase: 'final', scores: [0.05, 0.05, 0.9]})`；这些入口仅用于静态原型，没有真实 Agent 或事件总线。

## 已执行的原型验证

通过仓库固定版本 `pnpm exec playwright cli`，附着本次专用 Chrome，以 1440×1020 验证，共 15 项通过：开启仅最终回复、从 0 计数、中间回复不续接、最终回复触发、草稿保留、暂停不续接、恢复不归零、最多 3 次、上限不等于完成、取消重新开启保持计数、展开判定详情、完成/受阻/判断中三个场景、390px 窄屏无横向溢出。浏览器控制台无 error。

这不是实施计划中的真实运行时或模型语义验收。没有创建单元测试文件；浏览器检查脚本仅为本次临时验证。
