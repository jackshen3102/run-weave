## 打开

首选从 Runweave 的原型库打开 `desktop-secondary-pages`。也可以在仓库根目录启动独立静态服务器：

```bash
python3 -m http.server 6188 --bind 127.0.0.1 --directory docs/prototypes/desktop-secondary-pages
```

端口被占用时可改为其他空闲端口或 `0`，以终端实际输出为准。打开输出的 `http://127.0.0.1:<port>/`。页面需要 HTTP 加载 JSON，不能直接使用 `file://`。

## 原型简报

- 目标：统一全部桌面菜单、设置和二级页面的归类、视觉与返回行为。
- 保留：项目顶栏、236px Worktree 栏、终端会话区、右侧工具区及其相对位置。
- 主用户动作：打开应用菜单，进入独立页面，浏览列表与详情，编辑保存，返回原工作区。
- 关键状态：未保存、已保存、等待服务重启；空列表、读取失败、断连；当前连接、本台桌面、项目与随记账户作用域。
- 非目标：实现真实终端、浏览器原生视图、服务配置、任务运行、登录审批、SSH、RemoteDesk、真实危险操作或跨端数据同步。
- 这轮仅交付原型。实施计划与产品代码留待原型反馈后推进。

### 保持原位置的功能

项目的增删改/排序、Worktree 固定与管理、终端新建/分屏/搜索/附件、Fork、恢复 Agent、输出复制与快照、开发服务与当前 Browser 通道继续归属于原工作区；菜单展示常用动作，复杂工作区交互仅提供背景示意。

右侧完整集合：Preview、Automation、Browser 1/2/3、Agent Team、Race、任务交接、任务监控、会话阅读。原型保留标签入口与切换，**未重做或完整模拟这些面板内部**。文件/Diff/Markdown 操作、Browser 标签/工作组/代理/Headers/设备模式/批注/CDP、Agent Team 人工裁决、Race worker、交接证据和监控恢复继续列为保留能力。

系统菜单的窗口、编辑、缩放、全屏、刷新、DevTools 保持原生；诊断导出、系统监控和本机运行时操作与二级页面统一归属。macOS 标题栏在原型中仅为静态背景，不模拟系统窗口管理。

## 交互决策

- 全屏占用应用内容区，进入二级页后隐藏原工作区；工作区 DOM 留存。
- 全局菜单是顶栏临时菜单，不新增常驻一级侧栏。
- 设置使用局部分类栏；其他模块使用自己的页内标签。
- 同一模块的分类切换不堆积返回历史；详情返回列表，模块返回进入前的页面/工作区。
- 列表搜索条件与工作区输入、右侧工具选择在同次浏览期间保留。
- 主题即时生效；模型、Browser、通知与配置显式保存。
- 切换页面/角色/Profile 之前处理未保存修改。
- 本台桌面、当前连接、Worktree 与随记账户分别展示作用域；账户与服务能力仍需真实实现核查。
- 删除、结束进程、释放资源、退出等使用就地确认。
