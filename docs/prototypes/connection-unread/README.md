# 连接数字角标原型

2026-10-29 的设计评审原型，模拟数据，不是生产实现。仅修改本目录，未修改产品代码。

## 最新手机方案（v5）

依据用户提供的手机首页截图，复用左上角现有连接按钮和下方的连接切换抽屉。

- 左上角连接按钮右上侧显示绿色数字角标，汇总当前连接以外的未读完成终端数。
- 角标中只有数字，不显示“待接管”“新完成”或“其他连接”等文字；总数为 0 时隐藏角标。
- 点击连接按钮或角标打开现有连接抽屉。每条连接右侧显示自身数量，同样只有绿色数字；0 时仅隐藏数字，该连接仍可切换。
- 保留当前连接的选中标识、连接详情和添加连接入口。离线连接保留上次数量并使用原有离线状态文案。
- 展开、收起和切换连接不清除计数。切换后入口重新汇总其他连接，排除刚选中的连接。
- 首页不再新增“其他连接”一行；此前的大号首页标题删除方向保留，底部搜索仅按原有样式展示，不新增搜索功能。当前连接的终端绿点仍在原终端行。
- 桌面也采用相同数字逻辑，详见下方桌面方案。

样例：本地 1、Linux 开发机 3、MacBook Pro 2、测试服务器 0。当前连接是本地时，入口角标为 5；抽屉显示 1、3、2，测试服务器不显示 0。切换 Linux 开发机后，入口变为 3（本地 1 + MacBook Pro 2）。

`count` 沿用此前现有完成绿点的未读终端计数，不是所有运行中任务、失败或待确认任务的合计，也不等同业务验收成功。原型没有新增真实状态协议。

## 桌面方案（v6）

- 在当前终端顶部的现有连接入口右侧显示绿色数字角标，汇总其他连接的数量；0 隐藏。
- 点击入口或角标，在原位置展开连接下拉列表，各行仅显示对应绿色数字，0 隐藏且连接仍可切换。
- 不再显示“其他连接 N 新完成”或“待接管”等角标文字；当前连接名称、选中标识和连接管理入口保留。
- 与手机采用相同样例和计数规则：入口 5；列表 1、3、2；切换到 Linux 后入口为 3；展开和切换均不确认已读。
- [桌面展开列表截图](desktop-number-badge-menu-v6.png)
- [桌面收起列表截图](desktop-number-badge-home-v6.png)

两张图均为 Chrome 1280 × 800 的可运行 HTML 原型截图。已用 Playwright CLI 实际检查总数、各行纯数字、切换重算、展开/切换不清数，以及零隐藏但连接仍可选择。桌面产品源码未修改。

## 运行

```bash
python3 -m http.server 6188 --bind 127.0.0.1 --directory docs/prototypes/connection-unread
```

- 手机首页：`http://127.0.0.1:6188/?surface=mobile`
- 直接展开抽屉：`http://127.0.0.1:6188/?surface=mobile&connections=open`
- 其他连接数量为零：`http://127.0.0.1:6188/?surface=mobile&pending=none`
- 桌面展开：`http://127.0.0.1:6188/?connections=open`

## 功能分类与边界

| 分类         | 内容                                                                                             |
| ------------ | ------------------------------------------------------------------------------------------------ |
| 产品核心意图 | 连接按钮数字角标、抽屉各连接数字、零隐藏、现有连接切换                                           |
| 原型辅助     | URL 状态参数、mock-state.json、终端样例内容；不进入产品界面或实施计划                            |
| 原型边界     | 电量、状态栏、搜索外观、详情及添加入口为视觉示意；不连接 Backend，不操作真实连接，不修改已读状态 |

原型本身不接入真实跨连接取数、按 host 去重或跨端已读同步。v4“关注上方其他连接绿点”、桌面的文字摘要与更早的待接管卡片不再作为最新方案；旧图保留作历史材料。手机 v5 和桌面 v6 已获用户确认作为实现依据；当前产品行为见[完成通知说明](../../architecture/terminal-completion-notifications.md#连接入口的未读数字)。
