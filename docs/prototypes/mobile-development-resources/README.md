# 手机开发资源原型

2026-10-07 的历史交互草案，用户已确认并推进原生实现；此目录仍是样例原型，不是当前 iOS 实现或已发布能力。基于技能的 HTML 原型模板调整，无构建依赖、无真实资源请求，不会停止任何进程或释放设备。

用户目标：在手机查看当前连接电脑的桌面测试与 iOS 模拟器当前占用，并处理归属明确的占用残留。

入口建议：首页右上角「…」菜单，在「Mac 桌面」下新增一行「开发资源」。沿用现有导航进入独立页面；不新增首页横幅或独立底部 Tab。原型只实现新增功能的路径，其余现有菜单仅保留视觉上下文，不模拟对应业务。

## 浏览

```bash
python3 -m http.server 6198 --bind 0.0.0.0 --directory docs/prototypes/mobile-development-resources
```

- 默认首页：<http://127.0.0.1:6198/>。
- 入口菜单：<http://127.0.0.1:6198/?view=entry>。
- 桌面资源：<http://127.0.0.1:6198/?view=resources>。
- 模拟器资源：<http://127.0.0.1:6198/?view=resources&group=simulators>。
- 占用者变化：在资源页 URL 加 `&outcome=owner-changed`，确认时保留新的占用。
- 释放受阻：加 `&outcome=blocked`，确认后显示未释放并保留占用。

手机与电脑同一局域网时，可打开 <http://192.168.45.34:6198/>。这是本次电脑地址，服务需保持运行；更换网络后地址可能变化。

以上 URL 参数及 `window.prototypeMetrics()` 属于原型辅助功能，不进入产品界面或实施范围。所有任务、PID、UDID、数量、时间都是样例；页面中的时间是原型读取时间。

## 产品核心交互

| 区域     | 行为                                                                        |
| -------- | --------------------------------------------------------------------------- |
| 首页入口 | 「… → 开发资源」，返回首页不新增终端                                        |
| 当前连接 | 页面显示当前连接电脑名称，监控电脑测试资源，而非手机本身                    |
| 概览     | 桌面按物理槽位计数、模拟器按物理设备计数，待检查不算空闲                    |
| 列表     | 桌面 / 模拟器分段切换；全部、占用中、待检查筛选                             |
| 卡片     | 资源名、状态、任务、工作树、占用时长、最后活动；归属进程与路径默认折叠      |
| 刷新     | 进入页面读取一次；其后点击右上角刷新；无 5 秒定时、前台恢复或筛选触发的读取 |
| 释放     | 忙碌资源「停止并释放」；归属明确的残留「释放占用」                          |
| 确认     | 底部弹层显示电脑、资源、任务、工作树及中断影响；取消默认聚焦；取消不执行    |
| 结果     | 释放中禁止重复操作；成功更新占用与概览；受阻保留占用；旧确认不释放新 owner  |
| 保护     | 未知归属及当前提供接口的 Backend 无释放操作，显示原因                       |

原型额外保留桌面 5 个槽位和两台模拟器作为样例。手机列表分段显示两类资源，概览同时可见。

## 当前代码与原型差异

真实首页菜单位于 [HomeView.swift](../../../packages/app-ios/Sources/RunweaveIOS/Features/Home/HomeView.swift)，导航位于 [RootView.swift](../../../packages/app-ios/Sources/RunweaveIOS/App/RootView.swift)。现有「耗电监控」有独立页面及 5 秒轮询，不能照搬其刷新行为。

现有 Backend 已提供开发资源快照、释放合同与生命周期保护，见 [当前开发资源合同](../../architecture/development-resources.md)。原生 iOS 已接入该入口、Swift DTO 与页面，当前行为以该合同和产品代码为准。此历史手机原型仍没有接入真实 API，不验证远程释放是否成功。

原型创建阶段未实现产品代码；后续原生实现与此目录的样例交互验证分开。

## 原型验证

已使用仓库固定 Playwright CLI 附着当前内嵌浏览器的 profile-1，在新建原型标签页实际验证：

- 首页菜单进入、返回；进入计数为 1，等待 6.2 秒无自动刷新；手动刷新 +1，筛选与展开状态保留。
- 桌面停止释放、模拟器停止释放及残留释放：确认 → 释放中 → 空闲，概览随之变化。
- 取消默认聚焦、取消 / Escape 均不释放。
- 占用者变化仍忙碌；释放受阻仍占用；当前 Backend 和未知归属无释放按钮。
- 320px 宽度展开路径无横向溢出，402 × 874 完成最终截图。

这些仅为样例交互验证，不代表真机 App 或真实 Backend 释放验收。未改产品源码。
