遇到障碍时

对同一障碍实际尝试至少五种不同方案，全部失败且有证据，才报告该项受阻。每种记录改变的条件、结果和证据。任一路径恢复，立即重跑原场景并继续。需用户解锁等操作时，请求最小动作，同步完成其余独立项。
