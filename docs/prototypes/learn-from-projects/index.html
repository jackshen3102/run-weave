下一个项目，走哪条路？

根据功能现在所处的阶段，选择能观察到实际结果的办法。

  • 已经上线→比较上线前后同类任务，再从一次会话追到回执或产物。上面就是一个例子。
  • 有旧案例，尚未上线→拿同一批历史输入，分别跑旧做法和候选做法，列出哪些案例的结果变了。结论限于这批回放。
  • 全新功能→找一个确实要办这件事的人，记录第一次试用能否完成、卡在哪里、需要几次帮助。

本页评估的是知识整理功能。调研技能本身是否让建议更好，还需要后续真实使用记录。
