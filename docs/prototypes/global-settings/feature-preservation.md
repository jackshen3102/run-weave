## 验收底线

重构可以调整归类、布局与入口，但每项现有能力必须有可达的去向。检查单位是字段、操作和状态，而不是页面标题。普通、空数据、加载、失败、无权限、断连、保存冲突与操作进行中都属于功能合同。

- 同一作用范围、同一权限条件下，旧页面能完成的操作，新页面必须仍能完成。
- 不进入全局设置的功能，保留在所属业务、项目、终端或 Browser；“移出设置”不等于删除。
- 返回工作区必须保留项目、终端、右侧工具、输入草稿和运行状态。
- 整理布局不改变配置存储、默认值、凭据处理、服务生效方式或 API 权限。
- 不用较短的原型表单替换较完整的生产组件。所有未覆盖项补齐前，原页面和入口保留。
- 本轮源码核对与原型浏览器检查分别记录。静态示意、toast 和模拟成功不证明真实功能可用。
