## 原型简报

- 用户目标：在手机上了解桌面同一个终端的长任务进展，开关监控，查看理由，并在原会话处理阻塞。
- 关键原则：桌面与手机使用同一份 Backend 记录。开关、目标、最新判断、续接额度、活动和投递确认均来自同一状态；只调整展示层级，不创建手机专属任务或规则。
- 用户动作：从菜单或状态条进入；开关监控；查看判断依据、完整回复、输入来源、活动；回到原终端。
- 主流程：终端「…」菜单 → 长任务监控 → 开启 → 终端状态条 → 详情面板 → 判断依据 / 回到终端处理。
- 关键状态：未开启、监听中、判断中、本轮完成、需要处理、额度耗尽、投递未确认、错误、离线、无 Agent。
- 非目标：实现产品代码；修改 Backend 行为；全局任务中心；新增 APNs 通知；手机后台轮询；独立手机续接额度；自动审批。

## UI 与交互

1. 保留原生终端当前导航栏、四个标签与悬浮输入按钮。未开启时由已有终端菜单承载入口；已开启时在标签下方增加约 46pt 的整行状态按钮。状态条参与布局，不盖住终端输出。
2. 详情使用可滚动底部面板，固定标题与返回按钮，顶部保留上下文。右上角关闭、点遮罩和从顶部拖动条下滑均可关闭；关闭页面不修改后端开关。
3. 开关对应终端监听，不要求填写目标、选择任务起点或限定 Codex。状态与开关分开显示：本轮完成、阻塞、达到 3 次上限和投递待确认均保持开关开启。
4. 首层为开关、状态、目标、额度、最近判断与活动。第二层保留三分类相对评分、完整最终回复、投递状态、本次输入与来源、监听身份。评分不展示成正确率。
5. 需要处理或额度耗尽时，主按钮返回原终端，不审批权限、不自动发送“继续”。用户通过原有终端输入器发送消息后，新轮次额度按后端合同计算。
6. 离线显示上次同步状态并禁用写操作，不排队开关或消息。正常开启、关闭等待响应后再更新状态，不把请求中的状态当成功。
7. 本轮尚无有效判断时不显示旧结果为最新。生产实现如有历史判断，应标明“上次判断”并可查阅。

## 当前实现与历史原型

- 当前语义：[终端任务监控架构](../../architecture/terminal-task-supervision.md)。
- Web 实现：[监控面板](../../../frontend/src/components/terminal/task-supervision/panel.tsx) 与 [判断详情](../../../frontend/src/components/terminal/task-supervision/decision-details.tsx)。
- HTTP 合同：[共享 DTO](../../../packages/shared/src/task-supervision.ts)，已有发现、开启与 pause/resume API。
- 原生入口：[TerminalScreen](../../../packages/app-ios/Sources/RunweaveIOS/Features/Terminal/TerminalScreen.swift)、[终端操作菜单](../../../packages/app-ios/Sources/RunweaveIOS/Features/Terminal/TerminalActionsMenu.swift)。原型制作时尚未发现 iOS 监控 DTO、服务或视图接线；现有实现以以上当前架构入口为准。
- 原生实现已提供 Swift DTO、HTTP 服务与界面；前台同步与连接/终端切换隔离见上述 iOS 架构。手机与 Web 不各自计算监控结果或续接额度。
- 原型仅用 JSON 表达样例，没有连接 API，不证明跨端同步已实现。

## 验证与边界

通过仓库固定版本 `pnpm exec playwright cli`，在解析到的 Runweave Terminal Browser Profile 1 新标签内完成原型交互检查。已验证菜单开启后等待最终回复、关闭面板保留开启、额度耗尽仍开启、关闭再开启不重置额度、判断依据与输入来源跳转、阻塞返回原终端、本轮完成保持开启、离线禁用写操作、无 Agent 禁用开启；320px 窄屏无横向溢出。浏览器控制台无错误，`pnpm docs:check` 通过。

截图：[三屏画板](./prototype-preview.png)、[续接上限](./prototype-preview-limit.png)。原型交互与截图属于浏览器证据，不能代替原生模拟器或真机验收。

原型输入器只是返回原会话后的流程示意，不重设计现有 iOS 输入器。所有终端内容、来源文本、身份与评分均为样例。跨端开关冲突、真实 API 失败、后端动态更新和后台恢复未在原型中模拟；实际实现仍需遵循现有 revision 与连接生命周期合同。
