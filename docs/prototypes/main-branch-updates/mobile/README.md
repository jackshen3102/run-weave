## 启动

沿用父目录服务，在仓库根目录执行：

```bash
python3 -m http.server 6188 --bind 127.0.0.1 --directory docs/prototypes/main-branch-updates
```

打开 <http://127.0.0.1:6188/mobile/>。桌面浏览器中居中呈现 393×852 手机界面；窄视口全屏呈现，不依赖外部资源。

## 原型简报

- 目标：在手机上查看远端主分支中当前工作区尚未包含的提交标题，判断是否需要同步。
- 首页入口：关注列表中的 `main ↓14`，独立于打开终端的标题按钮。点击进入全屏“主分支更新”。无差异的 `main ✓` 同样可打开。
- 终端入口：打开终端 → 右上角操作菜单 → 主分支更新。不增加终端一级标签。
- 返回：从首页进入则返回首页；从终端菜单进入则返回原终端，保留原先状态。
- 列表：电脑、项目、工作区、比较的分支、差异总数、最多 10 个标题、短 SHA、作者、时间及检查时间。标题自然换行，列表单独滚动。
- 关键状态：有差异、无差异、检查中、失败保留旧结果与成功时间。
- 非目标：产品代码、真实 API/Git、安装到手机、逐文件 Diff、同步代码或完整 Git 图。

## 产品核心功能

| 内容                   | 行为                                     |
| ---------------------- | ---------------------------------------- |
| 首页现有主分支状态入口 | 独立触摸区，点击不打开终端               |
| 终端操作菜单新增入口   | 保留终端原有四个标签                     |
| 独立全屏提交列表       | 可看长标题，最多 10 条，同时显示总数     |
| 来源电脑与工作区       | 明确对比对象，不误读为其他电脑或分支     |
| 导航栏刷新、旧数据提示 | 不把失败当成已同步；失败保留最后成功时间 |
| 返回与滚动恢复         | 返回原入口，重开同一工作区恢复阅读位置   |

## 原型辅助功能

| 内容                             | 触发方法                                   | 边界                             |
| -------------------------------- | ------------------------------------------ | -------------------------------- |
| 直接进入列表                     | `?screen=updates`                          | 原型 URL，不进入产品             |
| 直接进入终端                     | `?screen=terminal`                         | 原型 URL，不进入产品             |
| 切换初始终端                     | `?terminal=focus` 或 `?terminal=main`      | 原型 URL，不进入产品             |

| 初始旧结果                       | `?screen=updates&state=stale`              | 原型 URL，不进入产品             |
| 850ms 刷新、终端输出、手机状态栏 | 演示数据与视觉壳层                         | 不是原生运行时或真机证据         |
| 首页其他工具、菜单其他条目       | 静态背景                                   | 未实现其业务操作，不新增产品需求 |

## 代码依据与缺口

- 当前首页依据 `packages/app-ios/Sources/RunweaveIOS/App/RootView.swift` 和 `Features/Home/HomeView.swift`，保留电脑入口、大标题、搜索、关注列表与项目分组。
- 当前 `HomeTerminalRow.swift` 整行是打开终端的 Button，分支状态在内部且不可独立点击。实际实现需拆成互不嵌套的点击区，不能在原按钮内嵌套按钮。
- `HomeBranchStatusModel.swift` 已展示默认主分支名称、落后数量与旧结果，缺提交列表与导航行为。
- `TerminalActionsMenu.swift` 已有终端操作菜单；本原型仅增加“主分支更新”入口。
- 终端背景和薄荷绿参考 `TerminalAppearance.swift`；其他列表按原生深色分组列表绘制。
- 尚需真实提交列表 DTO、Backend 接口和 Swift 消费。此原型不能证明这些能力、原生交互或真机访问已可用。
