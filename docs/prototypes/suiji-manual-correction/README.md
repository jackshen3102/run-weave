# 随记手动文字纠错原型

这是 2026-09-28 制作、持续用于交互评审的历史原型，不代表随记产品已经具备这些能力。本轮采用保守的显式收词：用户确认一个写法后才加入词库，先验证纠错效果。

## 启动

在仓库根目录运行：

    python3 -m http.server 6188 --directory docs/prototypes/suiji-manual-correction

打开 http://127.0.0.1:6188/ 。宽屏为 Web 编辑抽屉，390 像素宽时为 iPhone 布局。

## 当前交互

- 手动点击“纠正文字”，查看一份纠正后的文字；“查看原文”可以展开对照。
- 点击“应用到草稿”才更新输入框，之后点击编辑器“保存”才更新记录。
- 纠正后的词带有浅色下划线。点击 Runweave，打开“记住这个写法”：正确写法和可选的误识别写法均可修改，明确点击“加入词库”后保存。
- 编辑器中选中一个短词，会出现“记住选词”。所选文字填入正确写法，误识别写法留空，由用户填写。
- 词库添加成功后提示“已记住”，并提供撤销；也可进入词库移除词条。
- 已有标准词只追加用户确认的误识别写法，不重复创建标准词。不确定的名字保持原文。
- 修改正文、保存记录、应用 Codex 纠错都不会自动收录；没有默认勾选、后台监听或自动学习开关。

影响的真实界面是 iPhone `RecordEditorSheet` 与 Web／桌面 `SuijiEditor`。目标仍是修正错词、语法和重复，保留原意与信息量。

## 验证路径

1. 点击纠正，打开“查看原文”核对；取消后正文不变。
2. 应用纠正，词库仍不包含 Runwave；手动改正文并保存也不增加词条。
3. 在结果中点 Runweave，取消“记住”不加词；确认后词库追加 Runwave，原有“润威夫”保留。
4. 添加后点“撤销”，只撤销本次词库添加，不改正文。
5. 在正文输入并选中 Castor，点击“记住选词”，确认后新增标准词；误识别写法可以为空。
6. 添加词条后取消纠错，已明确添加的词条保留，正文保持原文。两次操作各自生效。
7. 纠错等待期间修改正文，旧候选不能应用；关闭编辑器后不弹出延迟结果。

## 取舍与功能分类

| 元素或行为                               | 分类     | 说明                                       |
| ---------------------------------------- | -------- | ------------------------------------------ |
| 手动纠错、预览、原文展开、取消和应用     | 产品核心 | 用户确认后更新草稿                         |
| 结果中点词、正文选词、编辑并确认正确写法 | 产品核心 | 每次添加均由用户主动触发                   |
| 词库管理、重复校验、添加撤销             | 产品核心 | 管理长期保留的词和误识别写法               |
| 不确定词提示、旧候选失效                 | 产品核心 | 保留原词，避免覆盖新草稿                   |
| 固定替换样本、一秒等待、内存保存         | 原型辅助 | 模拟模型与服务器，不证明识别效果或跨端同步 |

采用“点词收录”作为当前版本；自动从用户修改中学习留待识别效果得到验证后再评估。此前的“默认勾选同时记住”和“应用纠错时自动加词”已取消。首屏不放演示控件。

参考了 [Typeless 的词库说明](https://www.typeless.com/help/quickstart/history-and-dictionary)、[Wispr Flow 的个人词库](https://wisprflow.ai/features)与 [Gboard 点词加入词库](https://support.google.com/gboard/answer/7068415?hl=en-GB)。前两者从用户改正的拼写学习；本轮按用户要求降低自动化程度，采用显式确认。

## 边界与后续

纠错是固定样本替换；词库、草稿、保存均为浏览器内存状态，刷新会复位。此原型没有真实 Codex、语音识别、后端请求或账号同步。它只能验证交互，无法衡量纠错准确率。

[早期实施草案](../../plans/2026-09-28-suiji-manual-transcript-correction.md)和其中的自动学习验收方案暂不作为本轮交互的实现依据。原型仍待用户评审；交互稳定后再调整实施计划与验收方案。
