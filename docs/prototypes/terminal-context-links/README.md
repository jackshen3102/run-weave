# 终端上下文关联交互原型

2026-10-18 的历史设计原型。相关功能已进入产品源码，当前合同见[普通终端任务交接](../../../frontend/docs/task-handoff.md#随记关联与来源阅读)。原型只记录模拟交互，不代表产品验收结果。

## 原型简报

- 目标：在已有终端内找回需求原文、最新补充和成果出处，减少跨会话回翻。
- 用户动作：按需关联一条现有随记，查看原文与跟进，从成果返回原会话。
- 主要流程：打开任务交接 → 读来源 → 查成果对应回复 → 返回当前会话继续输入。
- 关键状态：已关联、未关联、切换会话、原会话不可用、关联预览期间内容变化。
- 非目标：自动创建任务、自动改写目标、完成率、自动完成待办、任务看板、自动派发。
- 影响的界面：当前 Terminal 三栏布局中的任务交接侧栏，保留项目、worktree、终端和输入区域。

## 启动

```bash
python3 -m http.server 6193 --bind 127.0.0.1 --directory docs/prototypes/terminal-context-links
```

打开 [默认场景](http://127.0.0.1:6193/)。如 6193 已被其他进程使用，另选空闲端口，不停止其他服务。

文件：`index.html` 为壳层，`style.css` 为样式，`app.js` 处理交互，`mock-state.json` 存放合成示例。
采用 prototype-first-development 提供的静态 HTML 模板结构，无需安装或构建。

## 可点击的主要路径

1. 默认场景是随记标签编辑的继续核对。查看原始要求、后续补充、本轮输入及成果记录。
2. 点击“查看原文与跟进”，在同一侧栏阅读随记，随后返回任务交接。
3. 点击 Web 或 iOS 验证条目，查看该记录的来源。点击“查看对应回复”进入示例中的原会话，并定位成果回复。
4. 在输入框保留草稿，切换终端后返回；每个终端的草稿独立保留在当前页面内存。
5. 选择左侧“任务看板研究”。该会话默认不关联随记，不继承其他会话的内容。点击“关联随记”，搜索并选择相应记录，再明确确认。
6. 从“关联操作”解除当前会话的关联，其他会话关联保持不变。
7. “回到本轮对话”定位当前会话最后一条用户输入并收起侧栏；终端上方可以重新打开侧栏。

## 场景参数

| 地址               | 用途                         | 操作                                                       |
| ------------------ | ---------------------------- | ---------------------------------------------------------- |
| `/?state=unlinked` | 未关联的会话                 | 明确选择后才建立关联                                       |
| `/?state=missing`  | 原会话不可用                 | 点击“回到原会话”，保留原文、成果和当前终端，不创建替代终端 |
| `/?state=conflict` | 关联预览期间出现新的用户补充 | 选择随记并确认，系统拒绝旧预览；读取最新内容后再次确认     |

这些 URL 参数仅为原型辅助功能，默认不显示控制器，不进入产品功能范围。

## 功能分类

| 产品核心交互意图       | 范围                                                         |
| ---------------------- | ------------------------------------------------------------ |
| 原文和补充直接阅读     | 展示来源，不把模型提炼出的目标替代用户原文                   |
| 当前会话与来源分开呈现 | “本轮最新输入”属于当前终端；随记要求与成果来源保留自己的身份 |
| 按需关联与解除         | 由用户选择现有随记，不自动建卡；解除只影响当前会话           |
| 成果来源和原会话入口   | 查看原始回复与工作区，不将 Agent 报告升级为独立验收证明      |
| 原会话不可用反馈       | 不自动创建终端、不改绑到其他会话                             |
| 关联确认时发现内容变化 | 重新展示最新用户补充后再确认，不覆盖正文或忽略变化           |

| 原型辅助行为                   | 边界                                                                                 |
| ------------------------------ | ------------------------------------------------------------------------------------ |
| 示例会话、随记、时间和验证条目 | 全部为合成样例，不是当前线上记录；样例文字参考已讨论的使用场景，不能作为历史事实引用 |
| 草稿隔离和会话切换             | 仅在页面内存中模拟，不证明真实终端可以恢复、切换或保留草稿                           |
| 输入框发送                     | 仅追加本地示例用户消息，不调用 Agent，不制造自动回复，不修改目标和待办状态           |
| 冲突与不可用参数               | 用来查看交互，不证明后台协议已经存在                                                 |
| 浏览器窄屏                     | 只检查 HTML 重排，不代表原生 iOS 设计或验收                                          |

## 评审边界

- 当前采用的原型方向：沿用任务交接入口，只在需要时关联现有记录。
- 未采用：独立任务中心、自动建卡、状态看板、自动完成。
- 本轮不生成实施计划，也不修改产品代码。
- 产品交互尚未获用户确认；原型未冻结。后续仅根据反馈调整原型，明确授权后才进入实施。
